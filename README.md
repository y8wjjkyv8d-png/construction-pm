# ConstructionPM

Система управління будівельними проєктами: об’єкти, етапи робіт, прогрес, бригади та їх призначення.

Навчальний проєкт з дисципліни «Технології програмування» (ЗНУ, магістратура F3 «Комп’ютерні науки», заочна форма).

| Етап | Зміст | Де шукати |
|---|---|---|
| ПР1 | Архітектурна модель: діаграма компонентів UML 2.5 | [`docs/architecture/`](docs/architecture/README.md) |
| ПР2 | Програмна реалізація компонентів | `src/` |
| ПР3 | Автоматизоване тестування | `tests/`, `docs/testing/` |
| ПР4 | Контейнеризація та оркестрація | `deploy/`, `docs/deployment/` |
